# Aston

This is a discord bot with Cards!

... That's really it!

## Run it!

1. **Get a discord bot token** Create a discord account, if you have not done so, and go to https://discord.com/developers to get a bot token

2. **Use the .env.example** remove the ".example" after inserting your environment variables

3. **Download the latest node.js** visit https://nodejs.org and download the lastest version (v20+) 

4. **Download the required libraries** once installed use the npm package installer with `npm install`

5. **Run the code** finnally do `node .` with the directly at the root folder of Aston.

## What this bot does...

- It gives a sort of 'character' card spawning - to a dedicated channel OR randomly in all 'permissible' channels

- Let's you claim, upgrade, and fight using these character cards.

- Show off your powerful and rare cards to your friends!
